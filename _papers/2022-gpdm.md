## 한 줄 요약

Sliced Wasserstein Distance(SWD)로 두 이미지의 patch 분포 차이를 직접 최소화해서, 학습 없이 몇 초 만에 single-image GAN 수준의 이미지 생성(reshuffling, retargeting, style transfer 등)을 해낸다.

## 요약

고전적인 patch 기반 생성 방법은 patch nearest neighbor 탐색이 필요해 무겁고, bidirectional similarity(BDS) 같은 척도는 patch 분포를 실제로 맞추지 못한다. SinGAN 같은 single-image GAN은 patch 분포를 근사적으로 맞추지만 이미지마다 오래 학습해야 하고 mode collapse 위험이 있다. GPDM은 patch 분포 간 거리로 SWD를 쓰는데, 무작위 projection 하나에 대한 SWD 계산이 "이미지를 random filter로 convolution → 값 정렬 → L1 거리"로 끝난다는 점을 이용한다. 이를 coarse-to-fine 이미지 pyramid의 각 scale에서 gradient descent로 최적화하며, 초기값(noise, 늘린 이미지, content 이미지 등)만 바꿔 여러 작업에 같은 알고리즘을 쓴다. 결과는 GPNN과 비슷한 품질에 SinGAN보다 좋고, 큰 이미지에서는 GPNN보다 훨씬 빠르다.

## 핵심 정리

- 이론적 근거: SWD는 P=Q일 때만 0이 되는 metric이지만, BDS와 REMD는 support만 같으면 밀도가 완전히 달라도 0이 될 수 있음을 증명(sky/grass patch 비율 예시)
- 계산: projection 방향 w마다 conv2d(x, w)와 conv2d(y, w)를 flatten·sort한 뒤 L1 차이. 매 iteration마다 k개의 random projection을 새로 뽑으면 exact SWD gradient의 unbiased estimate가 된다. 복잡도 O(M log M), nearest neighbor 불필요
- 구조: SinGAN/GPNN과 같은 multi-scale pyramid. 각 scale에서 Adam으로 patch-SWD를 최소화하고 결과를 upscale해 다음 scale 초기값으로 사용
- 설정: patch size 7, gradient step 300, random projection 64개를 모든 실험에 공통 사용
- 적용: image reshuffling(작은 noise에서 시작), retargeting(목표 비율로 늘린 최소 scale 이미지에서 시작, patch 수가 다르면 작은 쪽 patch를 무작위 복제), style transfer(content 이미지에서 시작해 style 이미지 patch 분포에 맞춤), texture synthesis, image editing
- 정량 비교(reshuffling, SIFID↓ / Diversity↑): Places50에서 Ours 0.068/0.56, GPNN 0.065/0.5, SinGAN 0.082/0.5. SIGD16에서 Ours 0.069/0.67, GPNN 0.122/0.52, SinGAN 0.172/0.49
- 속도: 1024×678 생성 시 GPNN(exact NN)은 30분 이상, GPDM은 1분 미만. 1024² 이미지에서 SWD(64) 0.335초 vs exact NN 73.23초 vs IVF 근사 NN 5.530초
- 확장: 사용자가 특정 patch의 빈도를 높인 target 분포를 지정해 객체 개수 조절, 여러 출력 이미지 전체의 patch 분포를 target N개 복사본에 맞추는 batched-GPDM으로 다양성 확보

## 흥미로운 점

- "patch 분포 매칭 = convolution 두 번 + sort"라는 관찰 하나로 알고리즘 전체가 몇 줄로 끝난다
- neural style transfer의 Gram loss도 VGG feature 위의 분포 매칭(MMD)으로 볼 수 있다는 관련 연구 정리. 분포 매칭 관점으로 여러 방법을 묶어 보는 시각이 유용하다
- GPNN의 completeness 파라미터 α가 근사 NN(inverted index)과 잘 맞지 않는다는 분석 — 품질 저하가 근사 오차가 아니라 α 때문이라는 점
- batched-GPDM: 개별 이미지는 target과 분포가 달라도 전체 합은 보존하게 해서 다양성을 얻는 아이디어

## 한계와 의문

- patch의 상대 빈도까지 그대로 재현하는 것이 오히려 제약이 될 수 있다(원문 Limitations). 객체를 새로 추가하는 편집처럼 분포가 달라져야 하는 작업에는 맞지 않음
- 최적화 기반이라 좋은 local minimum을 보장하지 못해 artifact가 생길 수 있다(원문 Fig. 3)
- 정량 평가는 reshuffling의 SIFID/diversity뿐이고 retargeting, style transfer는 정성 결과 위주다
- 원문에 학회 표기가 없어 venue는 비워 둠. arXiv v3(2022-09) 기준
- pixel 공간 patch(7×7)만 쓰는데, 더 큰 구조나 의미 수준의 일관성이 필요한 장면에서는 어떻게 동작할까?
