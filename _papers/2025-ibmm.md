## 한 줄 요약

Bézier control point를 고정 간격이 아니라 임의의 시점에 둘 수 있도록 학습한 motion diffusion model(IBMM)로, 관절 단위 spatial constraint와 timing·ease-in/out을 animator가 정밀하게 조절할 수 있게 했다.

## 요약

선행 연구 BMM(Bézier Motion Model)은 hip, head, wrist, feet 같은 일부 관절의 motion을 cubic Bézier curve로 표현해 정밀한 joint-level control을 제공했지만, control point가 6 frame 고정 stride에만 놓일 수 있고 학습 전에 Bézier fitting이 필요했다. IBMM은 학습 때 control point의 개수와 시점을 무작위로 뽑아 노출시키고, Bézier fit은 dense trajectory loss로 암묵적으로(implicitly) 학습한다. 여기에 condition token 구성과 데이터 정렬 방식을 바꿔 constraint 정확도를 높이고, center of mass 궤적에서 계산한 ease-in/out 값을 새로운 조건 token으로 넣었다. LaFAN1 inbetweening 실험에서 BMM보다 handle accuracy와 foot sliding이 모두 개선되었고, 연속적인 시간 위치도 일반화함을 보였다.

## 핵심 정리

- **표현**: 관절 subset J의 global position과 6D orientation. 입력은 경계 프레임을 포함한 B개의 sparse pose(균일 크기 bin에서 index를 sampling)와 joint-wise position condition token. 출력은 각 시점의 position, orientation, tangent이고, cubic Bézier sampling으로 dense motion을 복원한 뒤 learned IK로 full skeleton에 매핑.
- **Implicit Bézier fit**: tangent를 입력으로 받지 않고, BMM의 Bézier point/tangent 직접 loss 없이 dense trajectory, orientation, condition, velocity, foot sliding/contact loss만으로 학습. 사전 Bézier fitting이 필요 없어 학습 파이프라인이 단순해짐.
- **구조**: transformer encoder 기반 diffusion. Condition token은 joint position과 joint ID를 별도 linear layer로 embedding하고, positional encoding은 joint ID 쪽에만 더한 뒤 concat. 데이터는 시작 pose를 원점에 두는 대신 시퀀스 중앙을 원점으로, 진행 방향을 정면으로 정렬 후 Z-score 정규화.
- **Ease-in/out 조건**: 앞/뒤 절반 구간에서 COM 궤적이 등속 운동과 얼마나 다른지를 E_i, E_o로 정량화하고 두 token으로 입력. Attention mask로 각 프레임이 해당하는 token만 보게 함. GT 대비 [-2, 2] 배율로 바꿔도 생성 결과가 입력값을 선형적으로 따라감.
- **실험 설정**: LaFAN1(약 4.6시간, 피험자 1–4 학습 / 5 검증). 30-frame 모델(Bézier pose 4–12개)과 90-frame 모델(10–24개), RTX3090에서 230 epoch(약 64시간). Latent 512 → 1024.
- **결과**: Handle accuracy(cm) BMM 2.563, BMM+1024 dim 1.409, IBMM 0.389(random 시점 0.418). Ablation: 기존 token·정렬을 쓴 IBMM은 1.326, 새 정렬 제외 0.639, 새 token 제외 0.690. Foot Sliding Ratio Locomotion(stride 2): walk 0.037, run 0.023으로 BMM과 GT보다 낮음. 두 control point 사이에 새 point를 옮기는 실험에서 BMM은 계단형, IBMM은 선형으로 반응.

## 흥미로운 점

- 학습 때 control point 시점을 무작위화하는 것만으로 transformer가 연속적인 시간 표현을 배운다는 점. 고정 stride에서 학습한 BMM은 중간 시점을 가장 가까운 stride로 사실상 반올림해 버린다.
- Ease-in/out이라는 애니메이션 원리를 COM 궤적에서 정량화해 연속적인 조건으로 만든 점. 데이터셋에 없던 수준까지 extrapolation한다고 함.
- Foot contact 근처에서만 control point를 촘촘히 두는 식으로 시간 해상도를 국소적으로 조절할 수 있다.

## 한계와 의문

- 저자들이 밝힌 한계: IK 단계는 다루지 않아 J에 속한 관절만 제어할 수 있고, frame 단위 IK는 시간적으로 매끄럽지 않을 수 있다. 모든 관절이 같은 Bézier timing을 공유한다. 경계 프레임이 항상 주어진다고 가정한다(inbetweening 전용).
- Text나 audio 같은 고수준 조건과 결합하면 어떻게 될까? Future work로만 언급된다.
- 정량 비교 대상이 BMM 하나뿐이다. 다른 inbetweening 방법과 비교하면 어떨까?
